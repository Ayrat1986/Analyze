 11. ГЛАВНАЯ МЕТРИКА (v25.0)
================================================================
  Δ (Delta) = GameR − SpeedR.
     • Δ > +30 → медлишь (риск цейтнота).
     • Δ < −30 → спешишь (риск ошибок).
     • Δ ≈ 0 → идеальный баланс.
  Твой Δ (90д) = +11 (баланс). Твой Δ (сейчас) = +102 (Фаза Калибровки).
  Главная задача: завершить калибровку и вернуть Δ в ±30.

 32. ИСКЛЮЧЕНИЕ БЕРСЕРКА ИЗ ACPL (v25.0)
================================================================
ACPL (точность) считается ТОЛЬКО по «нормальным» ходам.
Ходы, сделанные при остатке времени < 10 секунд (TRUE_BERSERK_CLOCK),
НЕ включаются в ACPL, accuracy, acpl_opening, acpl_middlegame, acpl_endgame.

Обоснование: в берсерке (<10 сек) игрок действует на рефлексах
(шахи, флажки), а не рассчитывает варианты. Включение этих ходов
в ACPL искусственно занижает GameR и раздувает StdDev.

✅ В game.py:
   if is_true_berserk_clock:
       moves_berserk += 1
       if loss > 0: loss_berserk += loss
   else:
       # Всё, что было раньше (10+ сек) — считается в ACPL
       ...

✅ moves_normal = our_moves - moves_berserk
✅ acpl = total_loss / moves_normal  (а не total_loss / our_moves)

⚠️ Blunders всё равно сохраняются (для 11_Trainer).
   Они просто не портят статистику точности.

⚠️ moves_in_winning_position, critical_moments, momentum_after_blunder
   считаются по ВСЕМ ходам (включая берсерк), т.к. это поведенческие
   метрики, а не метрики точности.
